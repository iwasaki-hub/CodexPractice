
# CodexPractice - Development Instructions

## Project Overview
This project is a sandbox for learning OpenAI Codex.

## Environment
- OS: Windows 11
- Editor: Visual Studio Code
- Version Control: Git and GitHub
- Runtime: Node.js

## Development Rules
1. Explain changes in Japanese.
2. Inspect existing files before editing.
3. Make small, incremental changes.
4. Do not modify unrelated files.
5. Run available tests after changes.
6. Report modified files and test results.
7. Ask before deleting files or installing dependencies.
8. Never expose secrets or API keys.

## Coding Standards
- Prefer simple, readable code.
- Use comments where helpful.
- Avoid unnecessary dependencies.
- Keep source code inside src/.
- Keep tests inside tests/.

## Workflow
1. Inspect the project.
2. Explain the implementation plan.
3. Make the requested changes.
4. Run tests.
5. Summarize results in Japanese.
